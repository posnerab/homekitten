# Menu bar artwork

`MenuBarMotif.png` is a transparent version of the HomeKitten house-and-cat
motif. The Mac build produces a 64-pixel PNG and displays it at 22 points.
The existing app icon remains unchanged. The native status item has a stable
HomeKitten autosave name and explicit visibility.

Created using the built-in image-generation tool with AppIconV2's 1024-pixel
icon as the reference and this edit prompt:

> Edit this icon to produce a transparent-background menu bar motif. Preserve the exact cream house frame and chimney, navy kitten with golden face details, and gold wifi arcs with teal dot. Remove ALL of the square navy background outside the house silhouette, replacing it with real alpha transparency. Keep the house and cat as a single centered compact recognizable cutout. Preserve the existing 3D style and colors, crisp smooth edges, no extra drop shadow outside the silhouette, no border, no canvas/background tile. Crop framing so the house nearly fills the square canvas with a small transparent margin. This will be displayed at 22 pixels tall in a macOS menu bar.
